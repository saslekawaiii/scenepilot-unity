# ADR 001 Локальный векторный поиск

Контекст. Пакет предназначен для установки в сторонний Unity-проект. Демонстрационный корпус содержит небольшое число документов; отдельная БД увеличила бы число процессов и требований к установке.

Решение. IVectorStore отделён от retrieval. InMemoryVectorStore выполняет точный cosine search с предварительным фильтром Scope и MemoryKind. Embeddings получает OllamaEmbeddingProvider от EmbeddingGemma. Индекс строится в памяти; смена embedding-модели требует переиндексации.

Альтернативы. Qdrant/Chroma как сервис, SQLite с векторным расширением, внешняя Python-служба LangChain/LlamaIndex. Они полезны для больших корпусов и постоянного индекса, но избыточны для текущей демонстрации.

Последствия. Прозрачная сложность O(Nd), независимый тест retrieval и отсутствие DB-сервера. Индекс теряется после завершения процесса; эпизодическая и разговорная память ограничена текущим сеансом, не постоянным сохранением игры.
