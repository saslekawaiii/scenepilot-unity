# ADR 002 Провайдеры и маршруты

Контекст. Доступность API, стоимость и формат structured output зависят от поставщика. Model ID не определяет API-провайдера.

Решение. ILLMProvider и IModelRouter изолируют NPC. OrchestratorProfile назначает Terrain, Dialogue и Planning. Native Ollama adapter сохраняет метрики inference; OpenAICompatibleProvider обслуживает явные совместимые endpoints, Groq и бесплатный Pollinations. Validation остаётся C#-алгоритмом.

Альтернативы. Один большой модельный endpoint для всех задач; SDK каждого провайдера внутри NPC; скрытое автоматическое переключение на mock. Отвергнуты из-за связности, невоспроизводимости и непрозрачного поведения.

Последствия. Маршруты можно менять без изменения NPC. Free cloud имеет ограничение частоты, потому в смешанном профиле только Dialogue использует cloud, а Terrain и Planning остаются локальными. Это практическое распределение задач, а не ансамбль голосующих моделей.
