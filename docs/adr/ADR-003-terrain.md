# ADR 003 Структурированная генерация рельефа

Контекст. Вывод полной карты высот моделью плохо контролируется, увеличивает объём ответа и затрудняет воспроизведение.

Решение. LLM интерпретирует описание в TerrainSpec. C# реализует seeded value noise, fBm, радиальный горный край, центральную долину, южное понижение и ограниченное сглаживание. Уровень воды задаёт горизонтальную плоскость. Высоты и окраска остаются алгоритмическими.

Альтернативы. Сгенерированная моделью heightmap; исполнение C# из ответа; импорт полноценного коммерческого terrain toolkit. Отвергнуты из-за ненужного объёма, недоверенного кода и иной цели проекта.

Последствия. Чёткая повторяемость в проверенной среде, ограниченная выразительность спецификации. Сглаживание не объявляется физической гидравлической эрозией. Вода визуальная и не моделирует гидродинамику. Regenerate разрешён только объекту с маркером GeneratedTerrain.
