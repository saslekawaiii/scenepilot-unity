# ADR 004 Проверка предложенных действий

Контекст. Корректный JSON не гарантирует право на передачу предмета, существование цели или достижимость NavMesh.

Решение. NpcDecision.Parse строго проверяет поля, типы, дубликаты и ограничения размера. ActionDispatcher проверяет реестр и разрешения, затем все действия на проекции инвентарей. TransferAction ограничивает дальность, остаток и общий бюджет. WorldAction проверяет полный NavMeshPath. Исполнение выполняется синхронно после проверки.

Альтернативы. Выполнение по мере разбора, прямой доступ модели к Transform/Inventory или исключительно модельный validator. Отвергнуты из-за частичных изменений и недетерминированного контроля.

Последствия. Неверная команда не меняет инвентарь. Пользовательские IGameAction должны соблюдать контракт отсутствия побочных эффектов Validate. Общая транзакционная отмена произвольного внешнего пользовательского action не гарантируется: для неё потребовался бы отдельный commit/rollback-протокол.
