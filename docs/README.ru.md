# Документация Unity Editor Agent

[English](README.md) · [Русский](README.ru.md)

Создавайте, изучайте и дорабатывайте проект в Unity Editor с выбранной вами моделью.

[О проекте](../README.ru.md) · [Релиз 1.8.1](https://github.com/saslekawaiii/unity-editor-agent/releases/tag/v1.8.1)

## С чего начать

1. [Установите пакет](getting-started.ru.md) и откройте чат.
2. Подключите [Ollama (English)](local-models.md) или [другой API модели (English)](custom-api.md).
3. Разберитесь с [режимами чата, контекстом и разрешениями (English)](chat-workflow.md).
4. Попробуйте [пример запроса (English)](examples.md) и проверьте результат.

## Название проекта и совместимость пакета

Unity Editor Agent — текущее публичное название проекта. Релиз 1.8.1 по-прежнему открывается через **Tools → ScenePilot → Chat** и сохраняет идентификатор пакета `com.worldweaver.toolkit`. Исторические заметки, скриншоты и протоколы сохраняют названия, использовавшиеся при их создании.
