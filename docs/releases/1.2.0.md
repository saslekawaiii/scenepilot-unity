# WorldWeaver 1.2

Unity-агент с привычным чат-интерфейсом: описание задачи, выбор модели и глубины, режимы «Спросить», «Спланировать» и «Выполнить». Исправлена общая центровка стартового экрана и поля ввода; узкая панель переключается на одну колонку и выдвижную историю.

## Что добавлено

- Подключение собственного OpenAI-compatible Chat Completions API или Ollama через форму. URL, ID модели и способ авторизации задаются без изменения C#.
- Сохраняемое задание с требованиями, проверками и свидетельствами; ограниченное продолжение после перезагрузки домена Unity.
- Просмотр C#, точные изменения существующих файлов, реальные компиляция и тесты, checkpoint и восстановление затронутого состояния с проверкой конфликтов.
- Изображения и снимок камеры для поддерживающей локальной vision-модели; потоковый текст ответа.
- Семантическая деревня с дорогами, местами, NavMesh, расписанием, воротами, управляемым игроком, доставкой письма, однократной наградой и сохранением состояния.
- 60 MD-навыков с источниками, зафиксированными версиями и лицензиями; выборочная загрузка подходящих инструкций.
- Полностью переработанная ВКР, отдельное ТЗ, 12 слайдов и доклад на 8:40. Основание оформления — программа ГИА ВолгГТУ для профиля «Разработка игровых и XR приложений»; административные поля и справка о заимствованиях требуют оформления в вузе.

## Проверено

Финальный программный срез R3: **397/397 EditMode и 9/9 PlayMode**, установка TGZ в чистый проект Unity 6000.3.27f1 с нулём ошибок компилятора. Целевые 20 тестов являются подмножеством 397. Центровка проверена в настоящем Unity при нескольких размерах окна, игровой сценарий — в Editor и собранном macOS Player.

Один реальный разговор локальной Qwen3.5 9B выполнил **7/7 заданных условий на R2**. Точный полученный C# затем отдельно проверен на R3: 11/11 условий импорта, компиляции, подключения и отката; измерены 60,068° за 2,002 с при 30°/с, неподвижный контроль отклонён. Результат разговора не присваивается более позднему коду и не является оценкой общей надёжности модели.

Отдельный запрос по настоящему изображению верно связал стороны и цвета и назвал синий шар. Красный куб назван более общим «параллелепипедом», поэтому строгий критерий названия формы **не пройден**. Исходный отрицательный результат сохранён. Превосходство над Unity AI и полная замена разработчика сравнительным опытом не установлены.

## Установка и модели

Откройте поставленный `UnityProject` либо установите приложенный `com.worldweaver.toolkit-1.2.0.tgz` через Package Manager → Install package from tarball. Для готового управления игроком требуется Active Input Handling: **Input Manager (Old)** или **Both**.

Новый API: **«Добавить API…» → URL и точный ID модели → ключ при необходимости → «Добавить и выбрать модель» → «Проверить соединение»**. Ключ из формы хранится в процессе Unity и после полного выхода вводится заново; для постоянной настройки можно указать имя собственной переменной окружения. Нативные Anthropic Messages, Gemini и OpenAI Responses требуют отдельного адаптера.

Подробности: [руководство API](https://github.com/saslekawaiii/worldweaver-thesis/blob/v1.2.0/docs/custom-api.md), [начало работы](https://github.com/saslekawaiii/worldweaver-thesis/blob/v1.2.0/README.md), [архитектура и границы](https://github.com/saslekawaiii/worldweaver-thesis/blob/v1.2.0/docs/agent-architecture-and-limits.md), [приёмочные протоколы](https://github.com/saslekawaiii/worldweaver-thesis/tree/v1.2.0/results).
