# WorldWeaver 1.2.1 — исправление поставки GitHub

Исправлены имена файлов выпуска и прямые ссылки из README. GitHub преобразовал кириллические имена при первоначальной загрузке; теперь файлы имеют устойчивые ASCII-имена и русские подписи. Локальные документы сохраняют привычные русские имена.

Исходники этой поставки закреплены тегом **v1.2.1**. Unity-пакет остаётся **1.2.0**: все 396 файлов программного среза R3, документы ВКР и ТЗ, презентация и доклад сохранены без изменений. Программные и модельные испытания повторно не запускались; их условия и границы описаны в [выпуске 1.2.0](https://github.com/saslekawaiii/worldweaver-thesis/releases/tag/v1.2.0). Исходный тег v1.2.0 сохранён.
