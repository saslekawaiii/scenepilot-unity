# ScenePilot 1.8.0 — preview

ScenePilot is the new product name for the Unity agent. The package ID and script identities remain compatible with existing installations.

## What's changed

- General agent recovery from repetitive reads, repeated plans and invalid native tool steps, with the original task and actual operation results retained.
- Behavioral failures stay unresolved until the implementation changes and a fresh check succeeds.
- Play Mode observations support explicit budgets up to 120 seconds, with virtual keyboard/mouse input and cancellation.
- Targetless Editor C# no longer creates an unwanted workspace GameObject.
- Shared checkpoint content is stored by hash, with integrity checks and bounded disk usage.
- Web research uses `smolagents`; pinned Unity reference skills and API recipes retain upstream attribution.
- New ScenePilot menu, product documentation, bilingual README and versioned validation reports.

## Validation

The exact published archive passed **824 Editor**, **27 Play**, **16 Python** and **11 runtime acceptance** checks. Two opt-in external Play tests were skipped.

Real model requests and independent saved-artifact checks cover warehouse interaction, UI/light binding, relative edits, official web documentation, a moving lift and a repaired physics scene observed for 30 seconds. Their original candidate versions and earlier failures are disclosed in the [validation report](../validation/1.8.0/README.md). These results do not establish arbitrary-task reliability or artistic quality.

A fresh hollow-mesh request on RC23 still failed the independent collision check and was stopped by the harness after repetitive steps. This unresolved case is included in the validation report and roadmap.

## Install or update

Use Package Manager → Install package from Git URL:

```text
https://github.com/saslekawaiii/scenepilot-unity.git?path=/Packages/com.worldweaver.toolkit#v1.8.0
```

Alternatively install the release TGZ. Open **Tools → ScenePilot → Chat**. A GitHub push does not automatically replace an installed Git/TGZ dependency. [Update guide](../updating.md).
