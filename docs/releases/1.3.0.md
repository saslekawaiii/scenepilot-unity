# WorldWeaver 1.3.0

Локальные Ollama-модели обнаруживаются автоматически. Добавлены 13 встроенных CC0-материалов и поиск, загрузка и назначение PBR-карт Poly Haven. У NPC появились свободный ввод игрока, собственная история, переключатель ИИ, ограниченные фоновые разговоры и обновлённый игровой интерфейс. Агент предлагает C# для новых механик без обязательного слова «скрипт»; код остаётся на просмотре до импорта.

## Проверки

На замороженном срезе R11 (`399f1c62f17f7ab007452810b76f3108f8b143e5`) прошли **601 EditMode и 21 PlayMode** проверка без пропусков. Прямая библиотека материалов прошла **19/19** за 44,418 с при повторе на неизменном коде/TLS; первый SSL-неуспех с явным встроенным fallback сохранён отдельно. Причина первой ошибки Unity не установлена. Новая установка LocalTarball в проект без прежней Library прошла **21/21**, exit 0, ошибок компиляции нет.

Точный просмотренный компонент R8 прошёл на R11 **11** условий импорта, настоящей компиляции, подключения и восстановления и **18** условий поведения с настоящими нажатиями F: синий → янтарный → синий, удержание без повторов. Новая модельная генерация для повтора не выполнялась: исходные 526 байт получены на R8 в свежем чате с явной подсказкой алгоритма после трёх сохранённых неудач.

Настоящий основной чат R10 с qwen3.5:9b/Deep выполнил один запрос поиска, свежей загрузки и назначения выветренной древесины за **451,128 с**, 26/26 и независимый смысловой PASS. Отдельный R11 также завершён: **26/26 за 533,599 с**, четыре раунда и настоящая свежая Rough Pine Door на исходной двери. Независимый смысловой разбор R11 дал PASS для соответствия выбранной поверхности запросу и применения к исходной двери; UV, изображение и общая надёжность не оценивались.

В разговоре NPC R8 модель 9B прошла 19 автоматических условий; смысловой итог **PARTIAL** сохраняет выдуманную предысторию и неестественную речь. Полные ответы занимали 23–47 с. Новый исходный профиль демонстрационных NPC R11 — 9B/512 токенов/150 с/retries 0/0,25/context 8192; он соответствует одному успешному временно настроенному нативному ответу R10, весь pipeline 120,522 с. Нативный разговор R11 без подмены профиля завершён за 142,789 с; обе геометрии 14/14, новая реплика видна в 640 × 480. Независимый итог: доставка/видимость PASS, смысловой PARTIAL, слабая обработка метафоры. По сравнению с R10 неизменны **196 из 197** Runtime/Resources файлов; изменён интерфейс прокрутки новой реплики и добавлена регрессия.

Исторические неуспешные модельные попытки сохранены вместе с независимыми смысловыми разборами. Статический разбор, компиляция и измерение поведения — отдельные этапы. Превосходство над Unity AI и универсальная замена разработчика не установлены. Художественные 3D-модели, риги и голос не добавлены.

Пакет содержит 554 файла. SHA-256 TGZ: `09be89bc8631b35635a42dd9cd52184f5734770e2b9e61337f4abc0bd68d0fc3`.

## Установка

В Unity 6000.3 откройте Package Manager → Install package from tarball и выберите пакет из комплекта. Либо используйте авторизованный Git:

```text
https://github.com/saslekawaiii/worldweaver-thesis.git?path=/Packages/com.worldweaver.toolkit#v1.3.0
```

Запустите Ollama, установите `qwen3.5:9b` для исходного профиля новой игровой демонстрации либо явно назначьте другую установленную модель и откройте Tools → WorldWeaver → Чат. Установленные completion-модели появятся автоматически. «Быстро / Баланс / Глубоко» меняет бюджет работы. Свой OpenAI-compatible или Ollama API добавляется через «Добавить API…»; секреты не записываются в проект. Для игрового примера нужен Input Manager (Old) или Both.
