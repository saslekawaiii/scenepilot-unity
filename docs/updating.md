# Обновление установленного аддона

Обновление репозитория на GitHub и обновление пакета внутри Unity — разные операции. Сначала сохраните свою работу, затем дождитесь окончания импорта и компиляции Unity.

## Пакет из TGZ

Архив фиксирует конкретную сборку. Новые коммиты GitHub не меняют уже установленный архив.

В **Window → Package Management → Package Manager** выберите **+ → Install package from tarball** и новый `.tgz`. Unity обновит зависимость проекта и перекомпилирует пакет. Закройте и вновь откройте окно WorldWeaver после завершения компиляции, если в нём остался прежний интерфейс.

Если путь в `Packages/manifest.json` уже изменён на новый архив, достаточно открыть этот проект и дождаться импорта. Не заменяйте содержимое архива на месте в надежде обновить кеш: используйте новый файл или явно переустановите пакет.

## Пакет из Git

Git URL с тегом или SHA закрепляет конкретные исходники. Для обновления используйте **Install package from git URL** с новым тегом или SHA. Например, путь пакета внутри этого репозитория: `?path=/Packages/com.worldweaver.toolkit`.

URL с веткой также не означает автоматическое обновление при каждом открытии проекта: разрешённая ревизия записана в `Packages/packages-lock.json`. Выберите пакет и нажмите **Update** либо снова установите нужный Git URL через Package Manager. Не удаляйте весь lock-файл: это затрагивает и другие зависимости.

## Локальный пакет

Зависимость `file:` на каталог исходников читает изменения этого каталога; Unity импортирует их и компилирует C#. Это отличается от `file:` на архив `.tgz`.

Проверьте в Package Manager выбранный **WorldWeaver Toolkit**, способ установки и версию. Если обновление не удалось, откройте Console: ошибки компиляции нужно устранить прежде, чем проверять окно агента. Обновление аддона само по себе не запускает новый запрос агента и не перестраивает уже созданный мир.

Официальные инструкции Unity 6: [установка и обновление Git-зависимости](https://docs.unity3d.com/6000.0/Documentation/Manual/upm-ui-giturl.html), [установка TGZ](https://docs.unity3d.com/6000.0/Documentation/Manual/upm-ui-tarball.html).
