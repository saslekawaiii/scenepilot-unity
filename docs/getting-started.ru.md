# Быстрый старт

[English](getting-started.md) · [Русский](getting-started.ru.md)

Установите Unity Editor Agent в существующий Unity-проект, подключите модель и начните с изучения сцены без изменений.

Текущее публичное название проекта — **Unity Editor Agent**. В версии 1.8.1 в Package Manager и меню редактора пока используется **ScenePilot**. Идентификатор пакета остаётся `com.worldweaver.toolkit`.

## Что потребуется

- Unity **6.3** (`6000.3`). Релиз проверялся с 6000.3.27f1.
- Чат-модель через локальную Ollama или OpenAI-compatible API с протоколом Chat Completions.
- Установленный Git, если выбираете установку по Git URL.

Перед первой задачей с изменениями сохраните сцену и создайте коммит или резервную копию проекта. Отдельный Unity-проект для установки не нужен.

## Установка пакета

### Через Git URL

Откройте **Window → Package Management → Package Manager**, затем **+ → Install package from git URL**. Вставьте:

```text
https://github.com/saslekawaiii/unity-editor-agent.git?path=/Packages/com.worldweaver.toolkit#v1.8.1
```

Дождитесь импорта зависимостей и компиляции. Этот URL закрепляет версию 1.8.1 и не переключается на новые коммиты автоматически. Настройка Git и ошибки установки описаны в [инструкции Unity](https://docs.unity3d.com/6000.3/Documentation/Manual/upm-ui-giturl.html).

### Из архива TGZ

Скачайте `com.worldweaver.toolkit-1.8.1.tgz` со [страницы релиза 1.8.1](https://github.com/saslekawaiii/unity-editor-agent/releases/tag/v1.8.1). В Package Manager выберите **+ → Install package from tarball** и укажите этот файл. См. [инструкцию Unity по установке TGZ](https://docs.unity3d.com/6000.3/Documentation/Manual/upm-ui-tarball.html).

Эта GitHub-сборка не является пакетом реестра с подписью Unity, поэтому редактор может показать уведомление об отсутствии подписи. Используйте указанный репозиторий или релиз и опубликованные контрольные суммы.

## Открытие чата

Выберите **Tools → ScenePilot → Chat**. Старый пункт **Tools → WorldWeaver → Чат** открывает то же окно. Текущий интерфейс использует русские подписи.

Если пункта меню нет, устраните первую ошибку компиляции в Unity Console и снова откройте окно.

## Подключение модели

### Локальная Ollama

Установите и запустите [Ollama](https://docs.ollama.com/quickstart), затем установите чат-модель, подходящую вашему компьютеру. При работающей Ollama замените `MODEL_ID` на выбранный идентификатор модели:

```sh
ollama pull MODEL_ID
ollama ls
```

Для запуска сервера из терминала используйте `ollama serve`. Если приложение Ollama уже работает, второй сервер не нужен. [Справочник команд Ollama](https://docs.ollama.com/cli).

Модели сервера `http://127.0.0.1:11434` появляются в списке **Модель помощника** автоматически. Выберите нужную. Кнопка **Обновить** обновляет список; фоновое обнаружение ждёт завершения импорта, компиляции, Play Mode или текущей задачи агента. Установка модели и загрузка в память — разные состояния: первый запрос может занять больше времени.

### Свой API

Нажмите **Добавить API…** и выберите **OpenAICompatible**. Укажите название в списке, базовый URL API провайдера и точный ID модели. Выберите поддерживаемый сервером формат ответа: `JsonSchema`, `JsonObject` или `Text`.

Введите либо ключ API на текущий запуск Unity, либо имя существующей переменной окружения. Не помещайте ключ в URL. **Добавить и выбрать модель** сохраняет подключение; **Проверить соединение** читает метаданные без генерации. **Проверить ответ** отправляет небольшой запрос к модели и может расходовать квоту провайдера.

Пользовательские облачные подключения в 1.8.1 принимают текст. Протоколы Anthropic Messages и Gemini напрямую через эту форму не подключаются. Стоимость, бесплатные тарифы и доступность определяет провайдер.

## Первый запрос

Выберите **Спросить** и отправьте:

> Осмотри текущую сцену и объясни назначение её основных объектов. Не изменяй проект.

**Enter** отправляет сообщение, **Shift+Enter** добавляет строку. После успешного осмотра перейдите к [работе в чате (English)](chat-workflow.md) или попробуйте [пример запроса (English)](examples.md). Ошибки установки и подключения разобраны в [руководстве по устранению проблем (English)](troubleshooting.md).
