# Навыки встроенного агента WorldWeaver

Это библиотека **60 узких справочных навыков для самого WorldWeaver**, а не установка расширений Codex. Встроенный каталог находится в `Packages/com.worldweaver.toolkit/Editor/Skills`. Он поставляется в UPM-пакете и работает без сети. Сам по себе Markdown не обучает веса модели и не добавляет новые Unity-инструменты.

Содержание охватывает C#, архитектуру и lifecycle, scene/prefab/assets, Terrain и процедурную генерацию, NPC/NavMesh/память/квесты, UI Toolkit и UGUI, свет/материалы/шейдеры, анимацию, физику, аудио, сохранения, профилирование, тестирование и сборки. Каждый навык содержит конкретный подход и отдельную проверку наблюдаемого результата. Полный перечень получается через `AgentSkillCatalog.List()` или из `catalog.json`.

Адаптации не копируют upstream REST/MCP-вызовы, команды установки, режимы bypass или требования обращаться к недоступному серверу. Пакетные и API-зависимые операции описаны условно: если их нет в текущей схеме WorldWeaver, агент может дать совет или подготовить поддерживаемый C# draft. Из исходного performance-модуля не перенесены спорные обобщения стоимости ECS на обычные MonoBehaviour. Наличие внешнего навыка не подтверждает истинность всех его утверждений; версии и фактические результаты проверяются отдельно.

## Прогрессивное раскрытие

```csharp
var catalog = AgentSkillCatalog.CreateDefault(new[] { "Assets/AgentSkills" });
var metadata = catalog.List();                 // Только метаданные и доверие.
var found = catalog.Search("NPC должен обойти препятствие", 5);
var selected = catalog.Select(userRequest, sceneSummary, budget: 9000, maxSkills: 4);
// selected.Context — bounded reference data для контекста модели.
// selected.SkillIds / UsedCharacters / Warnings — для диагностики и UI.
string markdown = catalog.ReadStrict("ww-navmesh-baking", maxChars: 6000);
```

Маршрутизация детерминирована по двуязычным ключевым словам. Сначала учитывается запрос пользователя; scene summary может уточнить ранжирование, но не вводит навыки без совпадения с запросом. Загружается до 5 навыков; по умолчанию — до 4. Бюджет — **символы UTF-16, включая обрамление**, максимум 16 000, а не токены модели. При маленьком бюджете тело сокращается с явной пометкой. Пустой или неизвестный запрос не загружает всю библиотеку. Это простая retrieval-система, её точность не следует выдавать за полноценный семантический benchmark.

Сам чат использует более компактные настройки: до трёх навыков и 4 000 символов по умолчанию; в дополнительных настройках бюджет ограничен 1 000–12 000 символов. Это снижает объём входного контекста локальной модели. Значения выше относятся к общему API каталога.

В контекст ответа попадает операционная часть навыка до разделов «Граница применения» и «Происхождение»: один общий advisory-заголовок и полезные шаги вместо повторения одинаковых предупреждений и лицензий. Полный файл сначала проходит ту же проверку SHA. `ReadStrict`, исходные Markdown, лицензии и метаданные с URL происхождения остаются полными; это сокращение касается только выборки контекста модели.

## Пользовательские Markdown

В явно настроенном каталоге допустимы непосредственные подпапки `<id>/SKILL.md`. Поддерживаются однострочные поля `name`, `description`, `category`, `keywords`, `source`, `license`, `mode`. Только `name` и `description` обязательны; `mode`, если указан, равен `advisory`. Имя папки совпадает с ID из строчных латинских букв, цифр и дефисов. Вложенные исполняемые файлы и вложенные ссылки не загружаются.

Каталог ограничивает число корней/файлов и размер файла, принимает строгий UTF-8, отклоняет переходы пути, symlink на корне/пути навыка, повторные и неподдерживаемые метаданные, известные попытки подменить инструкции в метаданных. Отдельная проверка SHA перед чтением обнаруживает изменение файла после индексации. Внешний файл не может подменить встроенный ID или присвоить себе доверие через frontmatter. Изменённый встроенный файл с несовпавшим manifest SHA исключается.

Внешний Markdown всегда помечен `untrusted-advisory`, границы reference экранированы. Каталог **ничего не исполняет**, не читает `.env`, не вызывает shell/сеть и не меняет разрешения. Текстовое обрамление и фильтр метаданных не доказывают полной устойчивости модели к prompt injection: обязательной границей остаются текущая схема инструментов, валидаторы плана и исполнителя. Текст из навыка не может быть основанием расширять эти возможности.

## Воспроизводимость и проверки

```sh
python3 scripts/import_agent_skills.py                    # Проверка всех локальных SHA, без сети.
python3 scripts/import_agent_skills.py --build            # Детерминированная регенерация адаптаций и .meta.
python3 scripts/import_agent_skills.py --verify-upstream  # Повторное HTTPS-чтение exact pinned bytes.
```

Скрипт не устанавливает пакеты, не импортирует сторонний Python, не выполняет subprocess и не использует ключи. `AgentSkillCatalogTests` проверяет реальную библиотеку, русские/английские запросы, общий бюджет, неизвестный запрос, границы пути, изменение файла, недопустимые метаданные, кодировку и подмену ID. Первичная независимая от Unity компиляция и вызов 26 NUnit cases выполнены с настоящим каталогом; единственный stub — разрешение package path.

Последняя проверка в настоящем Unity 6000.3.27f1 подтвердила 30/30 тестов каталога и 10/10 transport-тестов. Полный зафиксированный снимок прошёл 300/300 EditMode и 9/9 PlayMode тестов без внешнего inference: отчёт с SHA снимка и XML (historical record retained locally). Он включает сокращение контекста навыков без изменения исходных файлов, 50 проверок схемы, host-валидации и выбора инструментов, 45 проверок workflow, 22 проверки проекции контекста и распознавания буквальных условий, интерфейс с общей осью чата и подключение пользовательского API. Проверка компактного контекста (historical record retained locally) отдельно фиксирует сохранение полных host-данных и доступность пропущенных объектов через инструменты. Проверка намерения создания мира (historical record retained locally) отличает новый мир от NPC/света внутри существующей долины. Нативная проверка интерфейса (historical record retained locally) содержит реальные скриншоты широкого и узких окон. Эти проверки подтверждают работу кода и границы каталога, а не улучшение качества ответов LLM.
