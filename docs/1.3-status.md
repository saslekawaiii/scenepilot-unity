# WorldWeaver 1.3: возможности и статус проверки

Текущий исходный пакет имеет версию **1.3.0**. Полная интеграционная проверка этого обновления продолжается. Последняя ранее опубликованная поставка — [1.2.1](https://github.com/saslekawaiii/worldweaver-thesis/releases/tag/v1.2.1); её документы, скриншоты и измерения остаются результатами указанного исторического среза.

## Что изменено

| Запрос пользователя | Реализованное поведение |
| --- | --- |
| «Запустил Ollama — модель появилась» | Автоматический опрос установленного списка на loopback; новые модели, подтверждённые capabilities, пометка памяти, сохранение выбора и своих API |
| «Хочу текстуры вместо одних цветов» | 13 оригинальных бесшовных CC0-наборов и поиск/загрузка настоящих PBR-текстур Poly Haven; отдельные операции поиска, импорта и назначения |
| «Хочу разговаривать с NPC своими словами» | Свободный ввод, история, переключатель ИИ персонажа, отмена запроса и сохранение контекста; отдельные проверяемые действия квеста |
| «Пусть NPC разговаривают друг с другом» | Личности и цели обоих участников, поочерёдные ответы выбранной модели, подход по NavMesh при подтверждённом пути, ограниченный общий бюджет |
| «Нужны новые игровые механики» | Выбор инструментов C# по смыслу механики, настройка предпочтения генерации, подготовка черновика для ревью, настоящая компиляция после применения |

Это описание реализованного кода и интерфейсных контрактов. Успех конкретной модельной беседы, корректность сгенерированного компонента и качество изображения подтверждаются отдельными испытаниями.

## Быстрый сценарий работы

1. Запустите Ollama и скачайте разговорную модель. Откройте **Tools → WorldWeaver → Чат**; список обновляется примерно каждые 10 секунд, при недоступном сервере — каждые 30 секунд. [Подробная настройка](local-models.md).
2. Опишите мир или изменение сцены обычной репликой. В режиме **Спланировать** сначала просмотрите план. Для существующих объектов указывайте цель или выделяйте объект в Unity.
3. Попросите подходящий материал: **«Найди текстуру выветренного дерева и примени к двери»**. Встроенные поверхности доступны без сети; онлайн-поиск ограничен Poly Haven. Загрузки не используют произвольные URL. [Библиотека материалов](material-library.md).
4. Попросите **«Включи ИИ у выбранного NPC и используй выбранную модель»**. В Play Mode подойдите и нажмите **E**, введите свою реплику. Общение персонажей и их автономное планирование включаются отдельно. [Настройка NPC](npc-ai.md).
5. Для новой механики опишите её наблюдаемое поведение: **«По нажатию F куб переключается между синим и янтарным»**. Параметр **«Создавать C# для новых игровых механик»** помогает агенту предлагать небольшие компоненты. Просмотрите код; после применения дождитесь компиляции и проверьте конкретный ввод/результат в игре.

Свои API добавляются через **Добавить API… → тип → URL + точный ID + ключ → Добавить и выбрать модель → Проверить соединение**. Поддерживаются OpenAI-compatible Chat Completions и Ollama. Ключ формы хранится до полного выхода из Unity; для постоянного доступа указывается имя внешней переменной окружения. Обычная локальная Ollama обнаруживается без заполнения формы. [Контракт подключения](custom-api.md).

## Какие проверки уже есть

- Новый сервис обнаружения с настоящим HTTP-транспортом выполнен против локальной Ollama вне редактора: четыре установленные модели, три completion и две vision; embedding-only отделена. Генерация не запускалась. [Точный протокол и исходник harness](../results/ollama-discovery-live-metadata-1.3.json).
- Выборочные программные проверки обнаружения моделей и выбора инструментов прошли на первом срезе 1.3. Они проверяют правила и жизненный цикл, используя локальные HTTP-fixtures и контролируемые ответы; это не качество inference реальной модели.
- Полная серия EditMode/PlayMode на интегрированном срезе R2 и фактические сценарии материалов, свободных NPC и подготовки C# собираются отдельно. Окончательные числа и ссылки добавляются после завершения каждого запуска и проверки его исходного среза.
- Наличие черновика C# не означает успешной компиляции. Успешная компиляция не доказывает поведение по нажатию F; для него требуется отдельная игровая проверка. Ответ NPC от тестового провайдера не считается диалогом настоящей модели.

Завершённые ранее **397 EditMode + 9 PlayMode**, разговор **7/7**, проверка просмотренного C# и исторический строгий vision-неуспех принадлежат серии **1.2**. Они сохраняются в репозитории и не переименовываются в результаты нового кода.

## Границы обновления

- Текстуры улучшают поверхность существующей геометрии. Генерация художественных 3D-моделей, ригов и голоса не добавлена. Встроенные карты имеют разрешение 256 × 256; онлайн-комплекты ограничены размером и проверяются по хешам.
- Поддерживаются Standard/Built-in и URP Lit; полноценный HDRP mask и физическая вода требуют отдельной работы. Проверенные на одном проекте материалы не означают совместимость с любой сторонней конфигурацией рендера.
- NPC используют ограниченную историю и фоновые квоты; они не получают неограниченную память или независимую большую модель на каждого персонажа. При ошибке сервера показывается ошибка, вместо подстановки вымышленного «ответа ИИ».
- Текст диалога сам по себе не выдаёт награду и не завершает квест. Предметы, расстояние, этап задания, навигация и действия продолжают проверяться детерминированно.
- Смена модели чата не перенастраивает всех существующих NPC. Для этого нужен явный выбор профиля или `assign_selected_model`.
- Новый C# остаётся просматриваемым исходником; выполнение произвольного кода не является песочницей. Контрольные точки имеют пределы и сохраняют конфликты ручных изменений.
- Бесплатный локальный маршрут работает без покупки API-токенов. Платные API не требуются; стоимость, квоты и правила явно выбранного внешнего сервера определяются его владельцем.

Универсальная замена разработчика, превосходство над Unity AI и статистическая надёжность на произвольных проектах этими проверками не установлены. Предмет обновления — конкретные инструменты, понятные действия пользователя и проверяемые результаты каждого сценария.
