# Принятые архитектурные решения

1. Unity 6000.3.27f1 LTS установлена из официального архива после обнаружения требования Unity 6+ в существующем ТЗ. Исходная Unity 2022.3.62f3 сохранена. Пакет дополнительно компилируется и тестируется в 2022.3, но основная демонстрационная версия — 6.3.
2. UPM-пакет находится в отдельной подпапке репозитория. Демонстрационный проект зависит от него по относительному local path. Git dependency использует `?path=/Packages/com.worldweaver.toolkit`.
3. Модель возвращает TerrainSpec или NpcDecision. Модель не пишет C# и не получает прямого доступа к сцене. JSON schema проверяет форму; C# проверяет смысл.
4. Ollama хранит модели вне репозитория, использует Metal на Apple M4. Qwen3.5 2B применяется для Terrain и фиксированного QA-сравнения, Qwen2.5-Coder 7.6B — для диалога и планирования игровой демонстрации, EmbeddingGemma — для embeddings. Все три модели реально вызваны по HTTP; установка файлов сама по себе не считалась доказательством inference.
5. RAG использует отдельный интерфейс IEmbeddingProvider и IVectorStore. Реальный baseline — EmbeddingGemma 768 измерений и exact cosine search, без сервера векторной СУБД. Это решение для малого корпуса, не обещание масштабирования на миллионы фрагментов.
6. Устойчивые знания, события и разговоры имеют разные типы памяти. Scope проверяется до поиска, в контекст включается ограниченное число фрагментов. Эксперимент QA отключает накопление диалоговой памяти, чтобы сравнивать именно эффект статических знаний.
7. Все действия решения сначала проверяются на проекции инвентарей. Запрещены неизвестные цели, превышение лимита и двойное расходование. После успешного предконтроля действия исполняются синхронно в главном потоке Unity.
8. Произвольные текстовые ограничения личности являются мягкими инструкциями модели. Жёсткие ограничения представлены отдельными полями: лимит передачи, разрешённые действия, дальность, разрешение TakeItem. Свободный текст не считается формальной политикой безопасности.
9. OpenAI вернул исчерпанный баланс, Groq — HTTP 403. По указанию пользователя платные запросы исключены. Бесплатный cloud-маршрут реализован через Pollinations Classic API с GPT-OSS 20B, без ключа, с интервалом 31 с и без платёжного кода.
10. Голосовой режим и извлечение PDF не входят в проверенный обязательный сценарий текущей версии. Импортируются TXT, MD и JSON. Ограничение явно отражается в документах.
11. Автономное планирование получает отдельное пересечение AllowedActions и PlanningActions. Тот же набор задаётся enum в JSON Schema и повторно проверяется dispatcher. Разговорная память исключена из Planning-контекста; эпизоды об исполненных действиях остаются. Это исправляет обнаруженную в реальном прогоне попытку повторить прошлую передачу предмета. Исходные неудачные прогоны сохранены в results/iterations.
12. Осторожный торговец вправе отказать в передаче без гарантий. Сквозной тест использует одинаковый ограниченный сценарий из максимум трёх предложений и сохраняет все ходы. После обсуждения долга проверяется изменение обоих инвентарей и фактическая позиция агента; скриптовой подмены решения модели нет. Два успешных маршрута не выдаются за статистическую оценку устойчивости.
