# Анализ аналогов на 30 октября 2026 года

Это исходный обзор для базовой версии 1.0. Последующее сравнение редакторского чата 1.1 с документацией Unity Assistant 2.21 вынесено в [актуальный протокол сравнения](/Users/kirillkovalenko/Documents/ChatGPT/Диплом/docs/research/chat-agent-comparison.md); историческая таблица ниже не переобозначается как проверка последней версии каждого продукта.

Сравнение выполнено по первичным источникам, перечисленным в sources.md. Знак «не установлено» означает отсутствие достаточного подтверждения в проверенной документации, а не доказанное отсутствие функции. Коммерческие продукты не устанавливались и не подвергались сравнительному нагрузочному испытанию.

| Решение | Подтверждённая область | Зависимости и ограничения сопоставления | Следствие для WorldWeaver |
|---|---|---|---|
| Unity AI Assistant и Gateway | Помощник Editor, генерация ассетов, интеграция сторонних агентов Claude Code, Cursor, Codex, Gemini | Проверенная версия документации Assistant 2.9 описывает доступ организации и назначенное место для Gateway/MCP. Произвольный runtime OpenAI endpoint или локальный NPC RAG из этого описания не следует | Нельзя писать, что Unity AI работает только со своими моделями. Сравнивать нужно authoring и отдельный runtime-контур NPC |
| Convai Unity SDK | Персонажи, знания, настройка действий, доступных целей и локальные executors | Наличие service API и dashboard; не проверены все условия тарифов и offline-режимы. Terrain не заявляется в рассмотренном разделе | Не объявлять действия и знания NPC новым изобретением; исследовать переносимость и общий процесс настройки |
| Inworld Runtime | Controller объединяет LLM, STT/TTS, embedding, knowledge и другие модули | Точная совместимость произвольных провайдеров требует отдельного испытания. Рассматривается как runtime-платформа, а не только облачный чат | Обосновать компактную локальную архитектуру, не утверждая отсутствие RAG у Inworld |
| NVIDIA ACE Game Agent SDK | C/C++ Agent, Chat, RAG API; отдельный стек on-device inference | Официальная страница описывает C/C++ интеграцию и NVIDIA-oriented inference. Полноценное испытание на M4 не выполнено | Не обещать CUDA на Apple M4; выбрать доступный Metal runtime |
| Promethean AI | Поиск, метаданные и размещение 3D-ассетов; основная интеграция Unreal и открытые плагины других редакторов | Поддержка конкретной версии Unity зависит от плагина. Продукт не следует сводить к генератору heightmap | Использовать как смежный инструмент окружения |
| Gaia и Procedural Worlds | Процедурное создание окружений Unity | Полнота биомов, спавнеров и ландшафтного authoring значительно шире учебного генератора | WorldWeaver не конкурирует по художественной полноте генератора |
| LLMUnity | Локальные LLM, персонажи и RAG в Unity | Уже закрывает значимую часть локального диалога. Следует учитывать распространение native inference-зависимостей | Вклад проекта состоит в интеграции TerrainSpec, маршрутов и проверяемого действия, а не в первом локальном NPC |
| LangChain и LlamaIndex | Общие retrieval-пайплайны и vector store abstractions | Python/JS-стек потребовал бы отдельного сервиса рядом с Unity | Для небольшого корпуса выбран локальный C# backend с заменяемым интерфейсом |
| Ollama, LM Studio, llama.cpp | Локальный inference и HTTP-интерфейсы | Каждый runtime имеет особенности JSON, отмены и метрик; совместимость нельзя выводить только из слова OpenAI-compatible | Ollama проверяется непосредственно, альтернативы остаются точками расширения |
| Coplay MCP for Unity | Управление редактором ассистентом разработки | Это authoring automation. Не заменяет runtime policy NPC | Разделять инструменты разработки и поставляемые игровые компоненты |

Выявленная задача — объединить повторяемую генерацию Terrain, индивидуальные знания NPC, разные inference-маршруты и детерминированные действия в переносимом учебном UPM-пакете. Анализ не доказывает уникальность такого сочетания на всём рынке. Практический вклад оценивается по воспроизводимости установки и измеряемому сценарию, а не по маркетинговому превосходству.
