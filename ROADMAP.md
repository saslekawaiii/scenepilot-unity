# ScenePilot roadmap

## Available

- [x] Chat-driven Unity scene and asset operations.
- [x] Local Ollama discovery and custom API connections.
- [x] C# generation, compilation, component wiring and reload recovery.
- [x] Actual Play Mode probes, input measurements and cancellation.
- [x] Web research with source and asset provenance.
- [x] Persistent task evidence and shared checkpoint storage.
- [x] Detection of repeated reads, unchanged plans and stale failure evidence.

## Next priorities

- [ ] Fix recovery after failed mesh/collider checks; stop repeated probes and historical reads on unchanged implementation state.

- [ ] Expand fresh-task evaluation across UI, geometry, animation and multi-scene projects.
- [ ] Improve visible progress and diagnostics for slow model connections.
- [ ] Broaden native Editor UI and cross-platform coverage.
- [ ] Add English UI localization.
- [ ] Improve asset matching, character rigs and visual result evaluation.
- [ ] Make model capability and cost constraints clearer before long tasks.
- [ ] Simplify installation and diagnostics for the optional web agent.

Each capability needs a working tool path and observable results. Adding a reference document alone does not close a roadmap item.
