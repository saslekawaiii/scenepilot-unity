# Village lore

Import `village-lore.json` using the KNOWLEDGE tab after selecting the merchant. Scope is assigned to the selected character by the importer. These are fictional test facts, not real-world information.

Create the complete playable sample with **Tools > WorldWeaver > Create Demo in New Scene**. The command creates scene assets and model profiles in the consuming project's `Assets/WorldWeaverDemo` folder. Ollama models are installed separately; see the package documentation.
