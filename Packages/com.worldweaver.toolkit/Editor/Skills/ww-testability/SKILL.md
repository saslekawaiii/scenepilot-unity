# Выделение тестируемых правил без чрезмерной абстракции

## Рабочий подход
1. Определи, какое правило можно вызвать без сцены и глобального состояния. Вынеси только это правило в обычный класс с явными входами.
2. Для Unity-facing кода оставь небольшой PlayMode тест с настоящими компонентами; полностью замоканная сцена не подтверждает интеграцию.
3. Проверка: тест ловит неправильный результат, а не повторяет реализацию; tiny scene-bound компонент не требует отдельной иерархии интерфейсов.

## Граница применения
Это справочный Markdown для встроенного агента WorldWeaver. Используй только объявленные в текущем запросе инструменты и их фактические схемы. Навык не добавляет shell, сеть, доступ к секретам, новые разрешения или автоматическое выполнение кода. Если операции нет, дай совет либо подготовь C# для просмотра в поддерживаемом процессе; не выдавай совет за выполненное действие.
