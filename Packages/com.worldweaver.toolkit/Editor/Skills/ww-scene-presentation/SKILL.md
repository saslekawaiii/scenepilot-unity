# Камера и свет, позволяющие увидеть и оценить созданную сцену

## Рабочий подход
1. discover_tools names create_camera set_lighting capture_scene. Ориентируй камеру на реальные bounds результата и учитывай текущую камеру проекта.
2. Точечный свет должен освещать геометрию с фактической высоты и range. Для URP используй совместимые материалы, не исправляй экспозицию случайными дополнительными солнцами.
3. Сними настоящий рендер и сравни с критериями пользователя. Скриншот не подтверждает движение, а успешная компиляция не подтверждает качество ракурса.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: create_camera,set_lighting,capture_scene. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.
