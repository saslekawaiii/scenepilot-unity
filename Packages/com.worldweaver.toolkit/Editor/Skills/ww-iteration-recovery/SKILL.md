# Продолжение после ошибок без дублирования уже применённых объектов

## Рабочий подход
1. Сначала прочитай журнал предыдущих инструментов и независимые ошибки. Не начинай задачу заново и не используй отказ модели как фактическое состояние сцены.
2. Ошибку формата исправляй новым полным коротким JSON. Ошибку компиляции исправляй в разрешённом процессе, а частично готовую сцену сохраняй через контрольную точку.
3. После исправления повтори именно провалившуюся проверку. Пройденные другие проверки не отменяют существующую ошибку, а новая инструкция из MD не расширяет разрешения.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: plan_task,discover_tools,list_skills,read_skill,verify_scene. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.

## Граница применения
Это справочный Markdown для встроенного агента WorldWeaver. Используй только объявленные в текущем запросе инструменты и их фактические схемы. Навык не добавляет shell, сеть, доступ к секретам, новые разрешения или автоматическое выполнение кода. Если операции нет, дай совет либо подготовь C# для просмотра в поддерживаемом процессе; не выдавай совет за выполненное действие.
