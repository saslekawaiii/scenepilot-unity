# Планирование Shader Graph по установленной версии и визуальному результату

## Рабочий подход
1. Версии Shader Graph и URP/HDRP определяют доступные nodes и target. Не предлагай отсутствующий узел без проверки версии.
2. Опиши входы, пространство координат и цепочку вычислений до изменения графа. Для процедурного эффекта зафиксируй ожидаемые диапазоны и освещение.
3. Проверка: preview и материал сцены дают одинаковый смысл; сохранение графа не потеряло порты. Недоступное редактирование графа остаётся рекомендацией.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: discover_tools,list_skills,read_skill,inspect_object. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.
