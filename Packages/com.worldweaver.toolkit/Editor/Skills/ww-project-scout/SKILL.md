# Краткое обследование существующего Unity-проекта до генерации новой системы

## Рабочий подход
1. Сначала установи версию Unity, pipeline, asmdef, папки кода, активную сцену и уже используемые packages.
2. Найди существующую реализацию нужной механики и проектные соглашения. Не создавай дубли PlayerController, Input или save service вслепую.
3. Проверка: новый план опирается на наблюдаемые имена и типы; неизвестные настройки честно помечены, секретные файлы не нужны.

## Граница применения
Это справочный Markdown для встроенного агента WorldWeaver. Используй только объявленные в текущем запросе инструменты и их фактические схемы. Навык не добавляет shell, сеть, доступ к секретам, новые разрешения или автоматическое выполнение кода. Если операции нет, дай совет либо подготовь C# для просмотра в поддерживаемом процессе; не выдавай совет за выполненное действие.
