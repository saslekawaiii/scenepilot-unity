# Volumes, профили и постобработка без скрытых глобальных изменений

## Рабочий подход
1. Определи систему post-processing и её пакет. Проверь volume layer, camera mask и активный профиль, прежде чем повышать значения.
2. Если профиль общий, создай осознанную копию для локального изменения. Не маскируй ошибочный свет экстремальной экспозицией.
3. Проверка: эффект включён на нужной камере, профиль сохранён, параметры не переопределяют чужие сцены.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: discover_tools,list_skills,read_skill,inspect_object. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.
