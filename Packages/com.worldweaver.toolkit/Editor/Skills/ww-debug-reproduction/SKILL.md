# Воспроизводимая диагностика до правки случайных настроек

## Рабочий подход
1. Зафиксируй ожидаемое и фактическое поведение, сцену, версии и минимальные шаги. Проверь compile/play state и обязательные ссылки.
2. Проверяй одну гипотезу за раз минимальным наблюдением. Отсутствие ошибки Console не доказывает правильность поведения.
3. Проверка: тот же сценарий до/после демонстрирует исправление; указаны непроверенные ветки и ограничения.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: discover_tools,list_skills,read_skill,inspect_object. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.

Это справочный Markdown для встроенного агента WorldWeaver. Используй только объявленные в текущем запросе инструменты и их фактические схемы. Навык не добавляет shell, сеть, доступ к секретам, новые разрешения или автоматическое выполнение кода.
