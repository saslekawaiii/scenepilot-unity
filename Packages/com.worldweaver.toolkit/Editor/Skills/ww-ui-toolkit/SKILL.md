# UI Toolkit UXML и USS с корректной жизнью подписок и адаптацией окна

## Рабочий подход
1. Разделяй структуру, стили и поведение. Используй flex sizing и минимальные размеры, чтобы узкое окно не скрывало ввод и кнопки.
2. Регистрацию callbacks делай симметричной и не накапливай её при повторном CreateGUI. Для больших списков учитывай виртуализацию.
3. Проверка: окно можно уменьшить, прокрутка не перескакивает при вводе, Enter и Shift+Enter имеют явное поведение, focus восстанавливается.
