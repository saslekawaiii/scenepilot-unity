# План сложной правки с журналом фактических результатов и остановкой

## Рабочий подход
1. Разложи запрос на маленькие наблюдаемые результаты с зависимостями и критериями завершения. После шага обновляй план по реальному readback.
2. Различай предложено, выполнено и проверено; не считай предыдущий разговор подтверждением сохранённого состояния после reload.
3. Проверка: незавершённый шаг не скрыт финальным сообщением; пользователь видит результат, оставшиеся ограничения и доступный способ продолжения.
