# Сохранение игры через версионированные DTO, стабильные ID и восстановление

## Рабочий подход
1. Сохраняй DTO со стабильными ID, версией формата и изменяемыми данными; ссылки на живые GameObject не являются переносимым save format.
2. Используй безопасную сериализацию и проверки входных данных; BinaryFormatter не подходит. Запись через временный файл и backup требует отдельного проверенного IO-механизма.
3. Проверка: новый слот, повторная загрузка, повреждённый файл и старая версия дают определённый результат. Markdown-навык сам не разрешает файловые операции.
