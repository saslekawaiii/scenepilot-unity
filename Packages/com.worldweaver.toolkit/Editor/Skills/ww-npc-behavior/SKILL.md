# NPC с восприятием, целями, памятью и отдельным исполнителем действий

## Рабочий подход
1. Разделяй восприятие фактов, выбор цели и выполнение действия. Локальные знания NPC не должны автоматически включать секреты всей сцены.
2. Для памяти задай источник, время, уверенность и срок хранения; авторский факт и слух не равнозначны. Цель должна иметь условие успеха, отказа и отмены.
3. Проверка: реплика опирается на разрешённые знания, действие действительно изменяет мир, недостижимая цель не объявлена завершённой; смена цели завершает предыдущее действие.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: create_npc,update_npc,configure_npc_ai,set_navigation,validate_world. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.
