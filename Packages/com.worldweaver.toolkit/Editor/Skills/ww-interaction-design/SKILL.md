# Осмысленные взаимодействия с предметами и интерфейсом

## Рабочий подход
1. Сначала определи ввод, адресата, дистанцию, изменение состояния и обратную связь. Используй штатный create_resource или create_ui_element button, если они выполняют запрос.
2. Для другого взаимодействия создай cohesive C# с явными ссылками, а не произвольным поиском объектов каждый кадр. Учитывай открытый разговор и заблокированное управление.
3. Проверь взаимодействие в пределах и за пределами дистанции, повторное действие и смену цели. Выведенная подсказка сама по себе не означает, что действие сработало.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: create_node,draft_script,attach_script,configure_survival,create_resource. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.

## Граница применения
Это справочный Markdown для встроенного агента WorldWeaver. Используй только объявленные в текущем запросе инструменты и их фактические схемы. Навык не добавляет shell, сеть, доступ к секретам, новые разрешения или автоматическое выполнение кода. Если операции нет, дай совет либо подготовь C# для просмотра в поддерживаемом процессе; не выдавай совет за выполненное действие.
