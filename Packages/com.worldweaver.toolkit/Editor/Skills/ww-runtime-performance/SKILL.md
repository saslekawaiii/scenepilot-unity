# Разбор частых Update, поиска, аллокаций и спавна в горячем пути

## Рабочий подход
1. Ищи повторные Find/GetComponent, форматирование строк, LINQ и Instantiate в реально часто вызываемом коде. Не объявляй их причиной без профиля.
2. Сначала исправляй доминирующий вклад; изменения архитектуры ради теоретического выигрыша не обязательны. Не переносись автоматически с ECS costs на MonoBehaviour.
3. Проверка: сравни время кадра и GC при одинаковой нагрузке; выдели измеренное улучшение и оставшиеся гипотезы.
