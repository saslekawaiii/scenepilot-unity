# Жизненный цикл assets, GUID и обратимые перемещения ресурсов

## Рабочий подход
1. Учитывай связку asset и .meta: стабильный GUID сохраняет ссылки. Перемещение не должно заменяться удалением и созданием нового файла.
2. Перед удалением проверь явные ссылки и владельца. Не объявляй файл неиспользуемым только потому, что его имя не встречается в открытой сцене.
3. Проверка: связанные prefab и сцены открываются без missing references; список новых файлов соответствует журналу операции.

## Граница применения
Это справочный Markdown для встроенного агента WorldWeaver. Используй только объявленные в текущем запросе инструменты и их фактические схемы. Навык не добавляет shell, сеть, доступ к секретам, новые разрешения или автоматическое выполнение кода. Если операции нет, дай совет либо подготовь C# для просмотра в поддерживаемом процессе; не выдавай совет за выполненное действие.
