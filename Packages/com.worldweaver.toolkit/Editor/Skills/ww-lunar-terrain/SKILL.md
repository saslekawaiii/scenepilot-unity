# Процедурные безводные инопланетные поверхности и ударные кратеры

## Рабочий подход
1. create_world style moon trees 0 buildings 0 создаёт каменистую безводную основу. Затем shape_terrain operation lunar задаёт кратеры; seed воспроизводит карту.
2. Это процедурная карта, а не измеренная топография NASA. Жителей, механику, пещеры и интерфейс добавляй отдельными штатными инструментами из соответствующих навыков.
3. Проверь формы чаши и обода, отсутствие воды и растений, границы и проходимость. Гравитация настраивается на игроке; Physics.gravity глобально не меняется.

## Доступные действия WorldWeaver
При необходимости вызови discover_tools с names: create_world,update_world,shape_terrain,create_cave,inspect_object. Это ссылки на существующие команды, а не разрешение на их автоматическое выполнение. После создания читай реальный target, затем применяй зависимые действия отдельным шагом.
