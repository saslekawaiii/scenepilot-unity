# WorldWeaver: quick start

Verified demonstration: Unity 6000.3.27f1 LTS. Open **Tools > Intelligent World Toolkit** after package import. Choose **Tools > WorldWeaver > Create Demo in New Scene** to generate a terrain, market, two scoped NPCs, local/free-cloud profiles and a playable dialogue.

Install Ollama and pull `qwen3.5:2b`, `qwen2.5-coder:latest` and `embeddinggemma`. Start Ollama at `http://127.0.0.1:11434`. Terrain uses the small model, dialogue/planning use the 7.6B local model. Free Cloud switches only dialogue to anonymous Pollinations Classic `openai-fast`; allow at least 31 seconds between cloud requests. No key or payment is required for this demonstration route.

WORLD interprets descriptions into editable TerrainSpec, then generates heights deterministically in C#. NPC exposes personality, goals, knowledge, permitted actions and hard constraints. KNOWLEDGE imports TXT/MD/JSON, assigns the current character scope and rebuilds local embeddings. MODELS assigns task routes. DEBUG displays retrieval, raw JSON and actual execution results.

GiveItem changes Inventory only after deterministic validation. Negotiation may take several turns and a refusal remains a legitimate model choice. Autonomous planning uses a separate action subset and excludes old conversation requests from its context. MoveTo/Follow/Flee require a working NavMeshAgent and NavMesh; the generated demo builds a small walkable market area at runtime.

Author persistent knowledge in a KnowledgeBase asset. Conversation and episodic memories are bounded runtime state, not a saved game database. PDF extraction and voice are outside the verified implementation. Keys belong in environment variables; a ModelProfile stores only their names. Never put keys into assets or Git URLs.

See the root README for reproduction commands, current limitations, raw experimental data and academic documents. The sample contains authored fictional lore for import; the complete scene is generated by the Editor command to avoid stale GUID references in a copied sample scene.
