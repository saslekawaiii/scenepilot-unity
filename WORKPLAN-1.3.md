# WorldWeaver 1.3 — материалы и живые персонажи

Базовый выпуск: [v1.2.1](https://github.com/saslekawaiii/worldweaver-thesis/releases/tag/v1.2.1). Тема ВКР сохранена. Исходные результаты версии 1.2 остаются привязанными к своим программным срезам.

- [x] Автоматическое локальное обнаружение Ollama, capabilities, отдельное состояние загрузки в память.
- [x] Офлайн-библиотека из 13 поверхностей и 39 карт; применение в создаваемых мирах.
- [x] Поиск и ограниченный импорт CC0-поверхностей Poly Haven, кеш, источник и лицензия.
- [x] Единый игровой экран диалогов, свободный ввод, портрет, история и действия квеста.
- [x] Включение ИИ для отдельного NPC, память и ограниченные разговоры NPC друг с другом.
- [x] Приоритет игрока, отмена, ограничения фоновых запросов, владение навигацией.
- [x] Инструменты и рекомендации для создания C# новых механик без обязательного слова «скрипт» в запросе.
- [x] Независимый просмотр кода, устранение найденных ошибок и регрессионные проверки.
- [ ] Общий запуск EditMode/PlayMode на зафиксированном снимке.
- [ ] Реальная загрузка и применение интернет-текстуры с чтением результата.
- [ ] Настоящие разговоры локальной модели и независимый разбор реплик.
- [ ] Настоящий черновик C# по запросу новой механики, просмотр и компиляция.
- [ ] Визуальная проверка игрового интерфейса в нескольких размерах окна.
- [ ] Финальные пакет, инструкции, доказательства и обновление GitHub.
