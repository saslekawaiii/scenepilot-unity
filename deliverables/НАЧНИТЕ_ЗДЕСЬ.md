## Запуск

Откройте `UnityProject` в Unity 6000.3.27f1 либо установите `com.worldweaver.toolkit-1.3.0.tgz` через Package Manager → Install package from tarball. Откройте **Tools → WorldWeaver → Чат**. Запустите Ollama и установите `qwen3.5:9b` для исходного профиля новой демонстрации; другую установленную модель можно явно назначить NPC. Список обновляется автоматически примерно через 10 секунд, а при выключенном сервере — через 30 секунд. Веса моделей в комплект не входят; локальный запуск не требует покупки API-токенов.

Выберите модель и глубину. **Спросить** читает и объясняет, **Спланировать** готовит изменения, **Выполнить** применяет допустимые действия. «Быстро» — до 1 шага и 2 минут, «Баланс» — до 3 шагов и 4 минут, «Глубоко» — до 6 шагов и 15 минут. Это пределы бюджета; скорость и правильность зависят от модели. Enter отправляет, Shift+Enter добавляет строку, **Остановить** отменяет ожидание. Меню **+** содержит задания и добавление изображений. Доступны 60 MD-навыков с происхождением и лицензиями.

Встроенная библиотека содержит 13 CC0-наборов/39 карт и работает офлайн. Для интернет-материала можно написать: «Найди на Poly Haven текстуру выветренного дерева и примени её к выделенной двери». Агент ищет, импортирует и назначает материал отдельными шагами. Для новых механик он предлагает C# без обязательного слова «скрипт»; исходник остаётся на просмотре перед импортом. Компиляция отдельно от проверки поведения в игре.

**Игровая демонстрация:** Tools → WorldWeaver → **Создать играбельную деревню** → Play. **WASD** — движение, правая кнопка мыши — камера, **E** — разговор. Напишите собственную реплику, Enter отправляет, Esc закрывает. ИИ можно включать отдельно у каждого NPC; фоновые разговоры и социальное движение также включаются отдельно. Квестовое действие выполняется явной кнопкой, а текст ответа не выдаёт награду. Save/Load находятся в игровом интерфейсе. Команда создания деревни исполняет заранее заданный процедурный план без LLM.

Готовый игрок требует Input Manager (Old) или Both. Для проекта только с New Input System нужна соответствующая интеграция ввода. [Модели](../docs/local-models.md) · [Материалы](../docs/material-library.md) · [NPC](../docs/npc-ai.md).

## Добавление своего API

В чате нажмите **Добавить API…**. Выберите Ollama или OpenAI-compatible, укажите URL и точный ID модели, затем способ авторизации. **Добавить и выбрать модель** помещает её в обычный список. Ключ из формы действует только в текущем процессе Unity; постоянная настройка хранит имя внешней переменной окружения. Нативные Anthropic Messages/Gemini требуют адаптера. [Пошаговая инструкция](../docs/custom-api.md).

## Официальные реквизиты ВКР

Оформление основной записки переработано по найденной программе ГИА профиля «Разработка игровых и XR приложений»: официальное задание, аннотации на двух языках, структура и поля. [Аудит требований](../docs/research/vkr-requirements-2026.md) различает локальные правила и действующие стандарты. В записке 101 страница, из них 80 до приложений; содержание включает 52 позиции.

ФИО руководителя, приказ, обозначения, утверждение и подписи оставлены пустыми, если подтверждающих данных нет. Год защиты 2027 взят из исходного задания. Справка о проверке заимствований оформляется через вуз после реальной проверки; вымышленная справка не создавалась.
