# WorldWeaver 1.6.0 — общий цикл агента и реальные ресурсы (preview)

Агент мог терять доступ к завершению, повторять уже сделанные настройки и останавливаться из-за отложенной сериализации Unity. Запрос на замену персонажа также упирался в два встроенных пресета. Выпуск меняет общий цикл работы, добавляет получение моделей и проверку результата по фактическому состоянию. Веса LLM не обучались.

## Изменения

- Исследование и `finish_task` доступны после неудачной попытки завершения. Протокольная ошибка возвращает модели точное имя недоступной функции и действующий список команд. Завершение различает выполненную, частичную и заблокированную задачу.
- До восьми независимых синхронных чтений можно вызвать одним ответом. Записи выполняются отдельно. Старые результаты доступны через `read_task_step`, включая реальные пути и ID.
- В режиме «Глубоко» отдельный модельный разбор проверяет весь запрос по новым измерениям Unity. Он запускается при завершении и после нескольких изменений. Для относительных правок используется исходное состояние обращения. Подтверждённое выполнение останавливает ненужные дальнейшие изменения. Повтор одинаковой уже применённой настройки ограничен.
- Измерения включают компоненты, физические размеры и шарниры, материалы, Terrain и привязки моделей. Новое физическое тело проверяется на наличие видимой геометрии независимо от названия задачи. Защита ручных изменений сохранена; исправлены источники ложных конфликтов со звёздным небом и зеркальными свойствами материалов URP.
- `model_search`, `model_import` и `replace_model` работают с ассетами проекта и каталогом 115 rigged-моделей людей Microsoft Rocketbox. Выбранные файлы загружаются из закреплённой ревизии; проверяются размер и Git blob SHA-1, сохраняются источник и MIT-лицензия. Каталог включён в пакет, сами модели загружаются по необходимости.
- Замена внешности сохраняет актор, управление, камеру, идентичность и память NPC. Управляемого героя можно сразу создать из импортированного FBX. Исправлены Biped-риг, Humanoid-маппинг и текстурные координаты материалов Rocketbox. Для Humanoid без совместимых клипов предусмотрена процедурная локомоция по костям.

Ранее импортированные 114 MD-навыков и 466 API-рецептов сохранены. Они помогают выбирать и реализовывать операции; это справочные данные, а не 580 самостоятельно исполняемых инструментов.

Восемь запросов включают создание героя, замену на реалистичную женщину с сохранением управления, физический балансир, собственный меш пандуса, чтение библиотеки без изменений, каменистый мир с оранжевой поверхностью и звёздами, увеличение высоты существующих гор и создание нового героя с реальной загрузкой модели, отсутствовавшей в кэше. Финальный прогон не потребовал протокольного восстановления. Более ранние неудачные попытки оставлены в `results` с номерами кандидатов.

Успешный тест физического балансира подтверждает геометрию и компоненты, а не устойчивость физической симуляции во всех условиях. Модельная оценка дополняет проверки Unity и может ошибаться. Два испытания ввода проверяют два конкретных импортированных персонажа; все 115 моделей каталога не проходили такое испытание.

## Открытые источники и границы

- [Microsoft Rocketbox, закреплённая ревизия](https://github.com/microsoft/Microsoft-Rocketbox/tree/0943055db6ec570bcef9f2c8b41c9e5467c808f9): MIT-каталог, модели и адаптация исправления импорта. Лицензия включена в пакет и импорт.
- [Coplay Unity MCP](https://github.com/CoplayDev/unity-mcp): изучен процесс поиска, загрузки и привязки ассетов; сохраняется ранее адаптированный MIT-компилятор. Платные генераторы не подключались.
- [Cline SDK](https://github.com/cline/cline/blob/main/sdk/ARCHITECTURE.md): изучены цикл наблюдений и состояние задач; код SDK не копировался.

Это предварительный исследовательский выпуск, а не гарантия выполнения любого запроса. Качество зависит от модели, провайдера, доступных ресурсов и проверки результата. Использован существующий временно бесплатный Beam; покупки и пополнения не выполнялись, постоянная бесплатность не обещается. Локальные модели поддерживаются, но указанные живые результаты относятся к Beam.

Rocketbox — библиотека готовых персонажей, а не генерация произвольной 3D-модели по тексту. Процедурная ходьба не равна авторским анимационным клипам. Автономный Editor C# работает с полномочиями Unity Editor, синхронно и без песочницы. Ограниченные контрольные точки не являются полным резервным копированием проекта.

Машиночитаемый протокол с хешами: [WorldWeaver-1.6.0-validation.json](WorldWeaver-1.6.0-validation.json). Установка: **Tools → WorldWeaver → Чат** после добавления TGZ в Package Manager. Для нового API используйте **«Добавить API…»**, укажите протокол, endpoint и точный ID модели; запущенная Ollama обнаруживается автоматически.
