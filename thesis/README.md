# Исходники пояснительной записки и технического задания

Основной редактируемый текст хранится в Markdown-файлах 00–06. Файл «ВКР_полный_текст.md» создаётся сборщиком. Тема сохраняется без изменения. Неизвестные реквизиты руководителя, обозначения и официального утверждения оставлены пустыми.

Сборка выполняется из корня репозитория командой `python3 scripts/build_documents.py`. Требуется Python 3.11+ и пакет `python-docx`; иллюстрации берутся из `docs/uml`, `docs/assets/screenshots` и `results/figures`, библиография — из `docs/research/sources.json`. Неизменяемый официальный титульный бланк включён в `thesis/templates`; его происхождение и SHA-256 приведены рядом. Закрытый каталог `.private` не требуется: скрипт создаёт в нём только промежуточный manifest и использует публичные `document-page-map.json` и `document-statistics.json`.

Результаты сборки: `deliverables/ВКР_WorldWeaver.docx` и `deliverables/Техническое_задание_WorldWeaver.docx`. PDF получен из этих DOCX средствами LibreOffice; при смене версии программы или шрифтов пагинация может измениться. Для переноса необходим Times New Roman. Формулы представлены нативным OMML и остаются редактируемыми в Word.

Содержание содержит проверенные номера страниц и внутренние ссылки на разделы. После изменения текста документ нужно снова преобразовать в PDF, запустить `python3 scripts/map_document_pages.py путь_к_PDF`, скопировать `.private/build/page-map.json` в `thesis/document-page-map.json`, обновить число страниц в `thesis/document-statistics.json`, повторить сборку и проверить пагинацию. Для окончательной редакции все страницы DOCX отрендерены и визуально проверены; протокол передаётся в results/document-qa.json.
